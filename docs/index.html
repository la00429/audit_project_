Funcionalidades

Todo lo que necesitas para auditar

Siete reglas WCAG 2.1 evaluadas automaticamente, deteccion visual de errores de layout, y reportes que puedes compartir.

🔍

WCAG 2.1 Nivel AA

Contraste, alt text, labels, headings, landmarks y botones sin texto accesible.

📐

Deteccion visual

Analiza bounding boxes del DOM para encontrar overflow y elementos fuera del viewport.

📊

Reporte HTML interactivo

Screenshot anotado con marcadores clickeables. Abre en tu navegador y navega los issues.

🔧

Sugerencias de fix

Cada issue incluye una sugerencia concreta de CSS/HTML para corregirlo.

🚫

CI/CD y Git Hook

Exit code 1 en criticos, salida JSON, y hook pre-push que bloquea deploys rotos.

⚡

100% local

Puppeteer headless en tu maquina. Sin APIs externas, sin latencia, sin costos.

Como funciona

Tres pasos, un resultado

De URL a reporte en segundos.

Navega la pagina

Puppeteer abre la URL en un navegador headless y toma un screenshot.

Extrae el DOM

Recopila bounding boxes, estilos computados y atributos de hasta 500 elementos.

Ejecuta las reglas

El motor evalua 7 reglas WCAG + deteccion visual contra los metadatos extraidos.

Genera el reporte

HTML interactivo con screenshot anotado, o JSON para tu pipeline de CI/CD.
