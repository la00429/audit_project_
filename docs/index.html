AuditTest Vision

Herramienta CLI que automatiza la auditoria visual y de accesibilidad web para desarrolladores. Un comando, cero configuracion, resultados inmediatos.

Ver en GitHub

El problema que resuelve

Cada vez que haces deploy, deberias revisar accesibilidad y errores visuales. Pero es tedioso, repetitivo y facil de olvidar. AuditTest Vision lo hace por ti en segundos.

$ npx audittest-vision https://tu-sitio.com --fix

Funcionalidades

CLI Local

Funciona 100% en tu maquina con Puppeteer. Sin APIs externas, sin costos, sin latencia.

WCAG 2.1 AA

Evalua contraste, alt text, labels, headings y landmarks automaticamente.

Auto-Fix

Genera sugerencias de CSS/HTML para corregir cada problema detectado.

CI/CD Ready

Exit code 1 en issues criticos + salida JSON para integrar en pipelines.

Chrome Extension

Boton flotante en cualquier pagina. Resultados visuales con badges de severidad.

Git Hook

Bloquea push automaticamente si detecta problemas criticos de accesibilidad.

Desarrollo con Kiro SDD

Construido integramente usando el flujo Spec-Driven Development de Kiro IDE:

  1. Requirements — Requisitos funcionales en formato EARS (6 reqs + 4 NFRs)
  2. Design — Arquitectura microkernel, interfaces TypeScript, flujo de datos
  3. Tasks — 27 tareas en 6 fases ejecutadas secuencialmente
  4. Hooks — Validacion de API keys, lint automatico, gate pre-push
  5. Steering — Reglas de estilo y estandares persistentes

Tecnologias

TypeScript Puppeteer Chrome Manifest V3 Kiro IDE (SDD) Node.js WCAG 2.1

Instalacion rapida

git clone https://github.com/la00429/audit_project_.git
cd audit_project_
npm install
npm run package

# Usar el CLI
npx audittest-vision https://cualquier-sitio.com --fix
